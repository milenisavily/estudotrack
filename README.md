# EstudoTrack

> Academic study tracker with performance monitoring and personalized recommendations.

---

## About

A terminal-based study management system developed as a final project for the Programming Fundamentals course (1st semester of Computer Science).

The program collects data about the student's subjects, study hours, goals, and current grades — then generates a complete performance report with personalized recommendations.

---

## Features

- Registration of up to 5 subjects
- Daily study hours tracking per subject
- Goal setting and completion percentage calculation
- Current grade recording and overall average
- Weekly study hours estimate
- Personalized recommendations based on performance
- Colored terminal output using `colorama`

---

## How to run

```bash
# Install dependency
pip install colorama

# Clone the repository
git clone https://github.com/milenisavily/estudotrack.git

# Run
python EstudoTrack.py
```
